# AI工具聚合站

免费AI工具资源聚合站

## 部署说明

### 自动部署（推荐）

1. 在GitHub上创建新仓库
2. 运行以下命令：

```bash
cd evolve/github-pages
git remote add origin https://github.com/你的用户名/ai-tools-gallery.git
git push -u origin main
```

3. 在仓库设置中启用GitHub Pages:
   - Settings → Pages
   - Source: Deploy from a branch
   - Branch: main, /(root)
   - Save

### 访问方式

部署完成后，站点将通过以下URL访问：
`https://你的用户名.github.io/ai-tools-gallery/`
