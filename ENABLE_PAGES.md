# Enable GitHub Pages

To enable GitHub Pages manually:

1. Go to: https://github.com/1003429073/model-free-link/settings/pages
2. Under "Build and deployment":
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
3. Click "Save"

Your site will be live at: https://1003429073.github.io/model-free-link/
